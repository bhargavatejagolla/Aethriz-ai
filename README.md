## 🏥 Overview

AETHRIZ is an AI-powered next-generation healthcare platform that unifies preventive cardiology, clinical tele-monitoring, computer-vision food macro analysis, 3D anatomical modeling, and patient journey sharing into a single glassmorphic experience.

---

## ✨ Features & Modules (Step 1 Complete)

### 1. Multi-Modal Landing Experience (`/`)
- **Fluid Dynamics & Bio-Neural Canvas**: 60 FPS interactive particle synapses with liquid light cursor dynamics (`SplashCursor`).
- **Interactive Component Wordmarks**: Integrated `TechText`, `StrokeText` SVG drawing, and `Shuffle` typography from React Bits.
- **Multilingual Support**: Real-time localized clinical interfaces across 24+ Indian and international languages (Hindi, Odia, Telugu, Tamil, Bengali, etc.).
- **Live Hospital ECG Oscilloscope**: Real-time Lead II cardiac rhythm sweep simulation with heart rate variability metrics.

### 2. AI Health & Risk Analysis (`/health-analysis`)
- Bayesian cardio-metabolic risk scoring engine (ApoB, systolic BP, glycemic index, sleep debt, VO2 max estimation).
- Ambient 3D Double-Helix DNA strand canvas (`DnaHelixCanvas`) with nucleotide base pairs.

### 3. Optical LiDAR Food Scanner (`/food-scanner`)
- Computer vision macro-nutrient analysis for whole food plates, Indian thalis, and beverages.
- Precision LiDAR crosshair matrix powered by React Bits `<ShapeGrid shape="cross" />`.

### 4. Interactive 3D Human Body Explorer (`/body-explorer`)
- Multi-modal developmental age cohort switcher (`2y Pediatric`, `12y Adolescent`, `28y Adult`, `68y Senior`).
- Gender phenotype toggle (Male / Female anatomy) with hemodynamic markers.
- 5 Organ Telemetry Systems: Myocardium & Coronary Arteries, Bronchial Tree, Cerebral Cortex, Hepatic Lobules, and Axial Skeleton.
- Raycasting diamond matrix background (`<ShapeGrid shape="diamond" />`) with zero lag and 60 FPS performance.

### 5. Verified Doctor Directory & Consultation Booking (`/doctors` & `/booking`)
- Specialist directory across Cardiology, Endocrinology, Genomics, and Preventive Medicine.
- Hospital ECG telemetry sweep background (`<CardiacPulseCanvas />`).
- Doctor scheduling with virtual/in-person consultation slots and interactive booking triggers (`HoldButton`, `FlyingButton`).

### 6. Medical Articles & Patient Stories (`/articles`)
- Real clinical survival narratives across ICU recovery, awake surgeries, near-death resuscitations, and chronic illness management.
- Liquid bioluminescent chromatic waves background powered by React Bits `<ColorBends />` (Three.js WebGL shader).

### 7. Clinical Portal & Queue Management (`/doctor-portal`, `/nurse-queue`, `/admin`, `/dashboard`)
- Multi-role EHR triage queue, vitals logging, and administrative governance.

## 🛠️ Technology Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **UI & Styling**: Tailwind CSS, CSS Custom Properties, Deep Multi-Layer Glassmorphism (`backdrop-filter: blur(24px)`)
- **Animations & Physics**: GSAP, Framer Motion, HTML5 Canvas 2D & WebGL Shaders (Three.js)
- **Component Suite**: React Bits (`TechText`, `StrokeText`, `Shuffle`, `ShapeGrid`, `ColorBends`, `RubberSegment`, `HoldButton`, `FlyingButton`, `SplashCursor`, `ElectricBorder`, `StarBorder`, `GlareHover`, `SpotlightCard`)
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites
- Node.js 20+ or 22+
- npm, pnpm, or yarn

### Installation
```bash
git clone https://github.com/bhargavatejagolla/Aethriz-ai.git
cd Aethriz-ai
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### Production Build
```bash
npm run build
npm start
```

## 🌐 Deploy to Vercel

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com/new).
3. Select the `Aethriz-ai` repository.
4. Click **Deploy**. (Zero extra configuration needed — all 17 routes build statically out of the box).
